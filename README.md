# Botswana Harvest Hub

https://www.eatseasonal.co/ striclty using HTML, CSS AND JS ONLY, use this website to bench mark. We want to develop a website that's in a split. First on the farmer's side, they should be and dashboard of their current balances from mobile payments, direct mobile transfers from sellers using Orange Money, Smega and MyZaka because there is no existing direct tunnel to send money from one mobile wallet to a different one here in Botswana. There should also be dynamic content based on season showing which produce thrive in a current season. There should also be an AI chatbot feature that predicts thriving produce for upcoming seasons, how the market goes and pricings for the produce in that seasons. And also prepare them for loan approvals in banks like ABSA. They should be able to adverise their business by uploading iamges, location mobile wallet details. Secondly consumers, they should be able to see advertised produce stalls in a marketplace like website arrangement, in their profile the mobile wallet details should be included, and they should be able to select locations in Botswana to see produce stalls nearby, Intergrate Orange Money, Smega and MyZaka into the website.
